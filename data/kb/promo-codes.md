# Promo codes and discounts

- One promo code per order.
- Codes must be entered at checkout. We cannot apply a code to an order after it is placed.
- Promo codes cannot be combined with the subscription discount.
- Codes cannot be used on gift cards.

If a code does not work, check its expiry date and minimum spend, then contact us.
